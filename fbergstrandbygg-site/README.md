# F. Bergstrand Bygg AB

Statisk hemsida för GitHub Pages.

## Innan publicering
- Byt projektplatshållarna mot riktiga projektbilder.
- Lägg in företagets riktiga Instagram-länk.
- Fyll i organisationsnumret i sidfoten.
- När sidan är publicerad på GitHub Pages kopplas `fbergstrandbygg.se` via DNS hos One.
- Den nuvarande loggan är sparad som `assets/logo-white.svg` och kan senare användas i header/footer; sidan har medvetet en enkel textmarkering tills vi bestämmer exakt placering.
